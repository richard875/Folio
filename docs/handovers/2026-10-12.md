## 📋 Project Overview

**Folio** is a private, authenticated article extraction API that implements the "Universal Article Reader" skill cascade. It fetches full article text + images from any URL, bypassing paywalls using a prioritized cascade of bypass services.

**Key Characteristics:**
- **Private API** — Single hash key auth (`<ACCESS_HASH>`)
- **No database/auth** — Stateless, `localStorage`-only (auth OFF per AGENTS.md §0.5)
- **Target deployment** — Oracle Always Free ARM VM (2 OCPU, 12GB RAM) or any Node.js host
- **Stack** — TypeScript, Fastify, `@mozilla/readability` + `linkedom`
- **Current status** — **95% success rate** (57/60 articles in latest batch)

## 🎯 The Cascade Strategy (Critical)

### Domain Classification

```typescript
// Premium domains → Freedium first
PREMIUM_DOMAINS = {
  nytimes.com, washingtonpost.com, bloomberg.com,
  reuters.com, economist.com, ft.com
}

// Archive-newest domains → archive.is/newest FIRST (positions 1-4)
ARCHIVE_NEWEST_DOMAINS = {
  wsj.com, axios.com, thehill.com,
  foreignpolicy.com, cnbc.com, businessinsider.com
}
```

### Probe Order by Domain Type

**Archive-newest domains (WSJ, Axios, Hill, FP, CNBC, BI):**
```
1. archive.is-newest     → https://archive.is/newest/<url>
2. archive.today         → https://archive.today/latest/<url>
3. archive.ph            → https://archive.ph/<url>
4. archive.is            → https://archive.is/<url>
5. freedium (cfd)        → https://freedium.cfd/<url>
6. freedium-encoded      → https://freedium.cfd/<encoded>
7. freedium-mirror       → https://freedium-mirror.cfd/<url>
8. freedium-mirror-enc   → https://freedium-mirror.cfd/<encoded>
9. removepaywalls.com
10. removepaywall.com
11. removepaywall.co
12. smry.ai
13. 12ft.io
14. wayback (web.archive.org)
15. wayback-id
16. googlebot retry
```

**Premium domains (NYT, WaPo, Bloomberg, Reuters, Economist, FT):**
```
1-4. freedium variants
5. archive.is-newest
6. archive.today
7. archive.ph
8. archive.is
9-16. rest of cascade
```

**Regular domains:**
```
1-4. freedium variants
5. archive.is-newest
6. archive.today
7. archive.ph
8. archive.is
9-16. rest of cascade
```

### Why This Order?

1. **`archive.is/newest`** triggers a fresh crawl — best for WSJ/Axios/Hill but rate-limited (429)
2. **Immediate fallbacks** (`archive.today`, `archive.ph`, `archive.is`) use existing snapshots — no rate limit
3. **Freedium** returns 404/paywall pages for many premium sites — deprioritized for archive-newest domains
4. **24h cache** on resolved archive URLs — subsequent requests skip `/newest/` entirely

## 🔑 Key Technical Decisions

### 1. No Direct Fetch
- Removed entirely — direct requests to publisher sites return paywall HTML
- All probes go through bypass services

### 2. 429 Handling (archive.is/newest)
- **First pass**: 429 errors propagate immediately, cascade continues to next probe
- **Second pass**: After all probes tried, wait 2s, retry **only 429'd probes**
- **Cache**: Resolved `archive.is/abc123/<url>` cached for 24h — future requests skip `/newest/`

### 3. Shell Detection (`extract.ts`)
Catches:
- Freedium 404s: "article not found", "404", "freedium - freedium", "unsupported site"
- Paywall pages: "subscription required", "subscribe to read", "sign up to read"
- Generic shells: "paste a link", "search the archive", "wayback machine has not archived"

### 4. Response Size Limit
- `MAX_BYTES = 3_000_000` (3MB) — archive.is pages can be ~1.8MB

### 5. Quality Gates
- `isSubstantial()`: ≥1400 chars AND ≥4 paragraphs (>40 chars each)
- Partial articles → HTTP 206, `partial: true`
- Full articles → HTTP 200
- Auth failure → HTTP 401
- Rate limit (24 req/min) → HTTP 429

## 📝 API Reference

### GET /api/read
```
Query params:
  url     (required) — URL-encoded article URL
  hash    (required) — Access key
  format  (optional) — "json" or "markdown" (default)

Responses:
  200 — Full article extracted
  206 — Partial article (short/truncated)
  401 — Invalid/missing hash
  422 — Could not extract (all probes failed)
  429 — Rate limited (24 req/min)
```

**JSON Response:**
```json
{
  "title": "Article Title",
  "author": "Author Name",
  "published": "2026-10-12T...",
  "originalUrl": "https://...",
  "text": "Full article text...",
  "markdown": "## Article\n\n**Title:** ...\n\n---\n\n## Images\n- image: https://...",
  "images": [{ "alt": "", "src": "https://..." }],
  "partial": false,
  "sourceUrl": "https://archive.is/abc123/https://..."
}
```

### GET /api/save
Same params as `/api/read`, plus:
- `website` (optional) — override inferred site name
- `section` (optional) — override inferred section
- `callId` (optional) — for batch tracking

**Saves to:** `output/articles/YYYY-MM-DD_HH-MM/site_section_title_HH-MM-SS.md|json`
